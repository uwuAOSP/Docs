# 系统小图标

系统小图标支持默认与 PUI 两种风格，通过 RRO 切换。

## 选择样式

进入 **uwuAOSP Plus > 界面设置 > 系统小图标**。

| 选项 | 行为 |
| --- | --- |
| 默认 | 关闭自定义覆盖层，恢复各组件原始图标资源 |
| PUI | 启用已预装的 PUI 风格图标覆盖层 |

选择后系统切换 RRO 并保存设置。个别界面需要重新打开才能刷新图标。

## 图标来源

PUI 图标位于 `vendor/uwu/overlay/rro_packages/PUI`，随 ROM 编译。

资源来自 **PUI Theme For Stock Android v17.0.218**，原作者 **天伞桜**。
