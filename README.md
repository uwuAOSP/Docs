# 外接屏桌面

外接屏桌面把 USB-C、HDMI 和受支持的虚拟显示器交给 Android 桌面模式。应用在外接屏上以可移动、可缩放的自由窗口运行，任务栏和窗口标题栏由系统桌面模式提供。

## 开启

进入 **uwuAOSP Plus → 系统与桌面 → 外接屏桌面**，打开总开关。

页面还提供两个独立选项：

- **遮盖本机屏幕**：外接桌面运行时，本机显示黑色连接提示；断开最后一块外接屏后自动恢复。
- **允许 scrcpy 虚拟屏**：允许 `scrcpy --new-display` 创建的可信虚拟屏进入桌面模式。普通屏幕镜像不会改变本机布局。

## 使用方式

连接支持视频输出的 USB-C 或 HDMI 显示器后，系统会把键盘和鼠标焦点指向外接桌面。也可以使用支持新显示器功能的 scrcpy，例如：

```sh
scrcpy --new-display=1920x1080
```

系统会把受支持的投影显示器按平板桌面处理，并为窄屏或竖屏设备计算适合桌面模式的密度和方向。它复用 Android 自带的自由窗口、任务栏、窗口标题栏和任务管理，不运行另一套桌面环境。

## 断开恢复

最后一块外接桌面断开后，系统会：

- 移除本机黑屏提示。
- 恢复本机显示和触摸交互。
- 把焦点返回内置屏幕。
- 结束只属于已移除显示器的桌面会话。

如果应用本身不支持自由窗口或多显示器，它仍可能以受限尺寸、固定方向或兼容模式运行。
