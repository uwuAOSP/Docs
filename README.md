# 应用传感器访问

应用传感器访问可以限制指定应用读取 Android SensorService 提供的动作和环境传感器数据。

## 设置策略

进入 **uwuSettingsExt → 应用传感器访问**，按应用名称或包名搜索，然后选择：

- **全部允许**：不增加额外限制。
- **打开后禁止 6 秒**：应用页面每次进入前台后，暂时阻止传感器访问 6 秒。
- **永久禁止**：持续阻止，直到用户修改策略。

“打开后禁止 6 秒”在应用页面重新进入前台时会重新计时。限制解除后，系统不会补发阻止期间遗漏的数据。

## 影响范围

受影响的应用可能无法读取加速度计、陀螺仪、距离、方向等由 SensorManager 或传感器直连通道提供的数据。

该功能不会限制：

- 相机和麦克风。
- 定位。
- 蓝牙或 Wi-Fi 扫描。
- UWB、NFC 和 USB。
- 应用启动、网络连接或后台运行本身。

系统原有权限、AppOps、全局传感器隐私开关和后台限制仍然独立生效。

## 使用限制

策略按 Android 用户和包名保存。“打开后禁止 6 秒”由应用 Activity 恢复到前台触发，无界面应用或仅启动服务的场景可能不会触发。

设置页面可能显示符合条件的系统应用。限制依赖传感器的系统组件可能造成异常，修改前应确认应用用途。
