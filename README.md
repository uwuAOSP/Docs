# Launcher 一览

Launcher 一览在第一屏顶部显示日期、天气、下一次闹钟、计时器和当前媒体信息。它是 Launcher 工作区的一部分，不占用普通小组件槽位。

## 显示内容

默认状态页会根据可用数据组合：

- 日期，点按后打开日历。
- 当前天气和预报，点按后打开天气页面。
- 下一次闹钟。
- 正在运行的计时器。
- 当前媒体标题、副标题和封面，点按后打开播放应用。

存在媒体内容时，可以横向切换状态页和媒体页，页数指示器只在有多个页面时显示。日期、区域、时区、闹钟和媒体状态变化会即时刷新。

## 设置

进入 Launcher 设置：

- **显示一览**控制整个第一屏状态区域，默认开启。
- **使用 Smartspacer**允许已安装并授权的 Smartspacer 提供卡片，默认关闭。

Smartspacer 不存在、被停用或权限检查失败时，Launcher 自动退回内置一览，不会留下空白区域。

## 数据来源

日期和闹钟来自 Android 系统服务，天气、计时器和媒体信息通过系统侧提供器读取。Launcher 不自行联网请求天气。设备或产品没有提供某类数据时，对应项目会隐藏，其余项目继续显示。

Launcher 设置和开关会随 Launcher 偏好备份。清除 Launcher 数据会恢复默认状态。
