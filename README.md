# 应用传感器访问

按应用管理加速度计、陀螺仪等传感器的访问。

## 配置

进入 **uwuSettingsExt > 应用传感器访问**，搜索应用并选择策略：

| 策略 | 行为 |
| --- | --- |
| 全部允许 | 不施加额外的传感器访问限制 |
| 打开后禁止 6 秒 | 应用 Activity 进入前台后，阻止传感器访问 6 秒 |
| 永久禁止 | 持续阻止传感器访问，直到用户修改策略 |

「打开后禁止 6 秒」会在应用页面每次进入前台时重新计时。

## 生效范围

策略作用于 `SensorManager` 和传感器直连通道。限制期间丢失的传感器事件不会补发。

相机、麦克风、定位、无线扫描等功能不受此策略控制。
