# 自定义字体

导入 TTF、OTF 字体，替换系统默认的 `sans-serif` 字体。

## 导入

进入 **uwuAOSP Plus > 界面设置 > 自定义字体**，选择 TTF、OTF 文件，或包含多个 TTF/OTF 文件的 ZIP 压缩包。

ZIP 在本机解压，字体保存在 `CustomTTF` 目录中，按名称、字重和样式列出。

导入限制：

| 项目 | 上限 |
| --- | ---: |
| ZIP 归档条目 | 256 |
| 字体文件数 | 128 |
| 单个字体 | 64 MiB |
| 字体总大小 | 256 MiB |

## 预览与应用

选择字体后，设置页展示中文、英文、数字和日文字符的预览。

```text
老人正梦见狮子。
The quick brown fox jumps over the lazy dog.
0123456789
いろはにほへと ちりぬるを
```

点按「应用所选字体」即可安装。失败时页面会显示原因。

## 恢复默认字体

「恢复默认字体」会移除字体覆盖并清空导入文件。应用字体或恢复系统字体后，可以重启设备让所有界面更新。
