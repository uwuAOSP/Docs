# 应用跳转控制

应用跳转控制允许限制一个应用启动另一个应用的 Activity，例如浏览器链接唤起购物应用或内容应用拉起商店。

## 配置规则

进入 **uwuSettingsExt > 应用跳转**。总开关默认开启；关闭后暂停执行现有规则，不删除配置。

规则可以按以下范围设置：

| 范围 | 匹配条件 |
| --- | --- |
| 来源应用 | 指定应用尝试打开其他应用 |
| 目标应用 | 其他应用尝试打开指定应用 |
| 应用配对 | 精确指定「来源应用 → 目标应用」 |

每项规则支持「始终允许」「询问」和「始终阻止」。配对规则的优先级高于来源或目标通用规则。

## 询问窗口

选择「询问」后，系统在跳转前显示来源和目标应用的名称及图标。

- 允许或拒绝后，本次启动按选择处理。
- 勾选「记住我的选择」时，将结果保存为对应应用配对规则。
- 未勾选时，选择仅对本次启动有效。
- 按返回键或点按窗口外侧会取消跳转，不保存规则。

阻止跳转时，系统会中止 Activity 启动并显示简短提示。

## 适用范围

该策略只作用于跨应用 Activity 启动，不限制 Service、Broadcast、ContentProvider、Binder 或网络通信。

同一应用内部跳转、系统来源、桌面、系统解析器、权限控制器、文件选择器和照片选择器等必要流程不受该策略限制。需要向来源 Activity 返回结果的启动通常保持 Android 原有行为。

卸载应用不会自动清除旧规则。重新安装相同包名的应用后，原规则可能再次生效。
