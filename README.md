# Prism

Prism 支持截图后框选文字或图片，进行 OCR、复制和导出。

## 启用三指手势

进入 **uwuSettingsExt > 智能 > Prism**，启用「三指上滑」。该选项默认关闭。

解锁屏幕后，三根手指同时向上滑动，即可打开截图选择界面。

## 选择与导出

在捕获页创建选区，可移动、调整大小或删除选区。

| 选区 | 支持的操作 |
| --- | --- |
| 文字 | OCR 识别、复制文本、导出 TXT 或 PDF |
| 图片 | 保存至 Pictures、导出图片或 PDF |

文字识别支持 uwuAICore 本地模型和内置的中英文 Tesseract。

## 保存

截图及 OCR 裁剪先保存在临时目录，选择保存或导出后才写入长期存储。当前捕获默认显示屏。
