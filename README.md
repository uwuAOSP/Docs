# 应用剪贴板权限

应用剪贴板权限在应用读取或写入系统剪贴板前执行额外的用户策略。它不会替代 Android 原有的权限、AppOps 和系统豁免，而是在这些检查通过后继续决定是否允许本次操作。

## 设置策略

进入 **uwuAOSP Plus → 隐私与安全 → 应用剪贴板权限**，可为每个应用选择：

- **允许**：保持 Android 默认行为。
- **询问**：应用访问剪贴板时显示确认窗口。
- **拒绝**：直接拒绝应用的读取和写入请求。

策略按 Android 用户和包名写入 `Settings.Secure`，重启后仍然有效。没有单独规则的应用按“允许”处理。

## 询问窗口

询问窗口会显示应用名称，并区分读取和写入请求。

- 未勾选“写入永久规则”时，拒绝只影响当前请求；允许会授予约 10 秒的临时访问权限，避免同一操作连续弹窗。
- 勾选后，选择结果会保存为应用的持久规则。
- 关闭窗口或按返回键等同于拒绝当前请求，不会保存规则。

系统会限制同一应用短时间内重复显示窗口。当前请求在等待用户决定前不会被放行。

## 适用范围

该功能覆盖 ClipboardService 处理的文本和剪贴板数据读写。Android 为输入法、系统组件、当前前台应用及其他受信任场景提供的原生豁免仍然有效，因此并非每次内部剪贴板调用都会显示窗口。

如果应用依赖后台读取剪贴板，选择“询问”或“拒绝”可能导致其自动填充、跨设备同步或剪贴板历史功能失效。
