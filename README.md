# 单独控制应用音量

应用音量控制为当前产生音频轨道的应用设置独立增益，不修改 Android 的全局媒体音量。

## 配置

进入 **设置 > 提示音和振动 > 音频 > 控制特定应用的音量**。该功能默认关闭。

开启后，系统音量面板会显示应用音量入口。打开后可以将当前正在播放的应用分别设置为 0–100。应用停止播放并释放音频轨道后，可能暂时不显示在列表中。

## 音频处理

SystemUI 通过 `AudioManager` 查询当前应用的音频轨道，把界面值 0–100 转换为 AudioFlinger 使用的 `0.0–1.0` 增益。

AudioFlinger 在混音时将应用增益与媒体流、输出端口的音量共同应用到音频上。因此修改某个应用的音量不会改变其他应用的增益；全局媒体音量仍控制最终输出响度。

同包名新创建的音频轨道会继承当前 AudioFlinger 进程保存的应用增益。修改其他应用音量的接口受到 `MODIFY_AUDIO_ROUTING` 权限保护。

## 限制

应用增益保存在 AudioFlinger 的运行时状态，不是持久用户设置。音频服务或设备重启后，应用音量恢复默认值。

没有独立音频轨道、使用特殊直通音频路径，或由其他进程代为播放声音的应用，可能不会以预期名称出现。
