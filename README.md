# Moment

Moment 将应用任务显示为可移动、可缩放的小窗，并保留原有页面和返回行为。

## 工作方式

Moment 基于 Android WindowManager 管理小窗，由 SystemUI、Launcher 和 uwuSettingsExt 提供入口与设置。支持多窗口、折叠、全屏切换及横屏适配。
