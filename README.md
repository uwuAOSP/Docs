# 状态栏歌词

在状态栏显示音乐应用提供的歌词，支持翻译和应用图标。

## 配置

1. 打开状态栏歌词总开关。
2. 将允许提供歌词的音乐应用加入白名单。
3. 选择显示位置：覆盖状态栏起始侧，或放在时钟右侧。
4. 根据需要启用翻译和应用图标。

总开关默认关闭，需要添加允许显示歌词的应用。

## 显示方式

| 位置 | 行为 |
| --- | --- |
| 覆盖起始侧 | 歌词占用状态栏左侧区域，暂时覆盖该区域的其他内容 |
| 时钟右侧 | 保留时钟，歌词显示在右侧；通知应用图标区域在歌词出现时暂时隐藏 |

歌词和翻译支持单行滚动与上下切换动画。触摸歌词可暂时隐藏，约 1.2 秒后恢复。

## 应用支持

音乐应用通过 `MediaSession` 等接口提供歌词信息，歌词与翻译以应用提供的内容为准。
