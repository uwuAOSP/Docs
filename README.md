# 状态栏歌词

状态栏歌词可以显示兼容音乐的实时歌词，并可选择同时显示翻译。

## 配置

使用前需要完成以下设置：

- 打开状态栏歌词总开关。
- 把允许提供歌词的音乐应用加入白名单。
- 选择覆盖状态栏起始侧，或显示在时钟右侧。
- 按需打开翻译和应用图标。

总开关默认关闭，白名单默认为空。空白名单表示不接受任何应用的歌词。

## 显示位置

### 覆盖状态栏左侧

歌词出现时，会覆盖整个状态栏左半边的其他内容，让歌词获得更大的显示空间。

### 时钟右侧

时钟继续显示，歌词位于其右侧。歌词出现时，通知应用图标区域会暂时隐藏。用户可以选择是否显示歌词来源应用的图标。

主歌词与翻译均为单行滚动文本，歌词更新时带有上下切换动画。点按或触摸歌词会暂时隐藏，约 1.2 秒后恢复。

## 应用兼容性

音乐应用必须支持 MediaSession，绝大多数 App 均支持此特性。
系统将自动获取歌词及其翻译（如果有），以及音乐 App 的单色图标，显示在指定位置。
