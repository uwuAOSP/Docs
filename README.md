# 智能建议

智能建议会根据当前内容或设备状态显示快捷操作，减少复制、切换应用和手动查找功能的步骤。

进入 **uwuSettingsExt → 智能 → 智能建议**，可以分别开启不同类型的建议。所有建议默认关闭；首次进入页面会准备剪贴板和验证码的默认规则，但不会自动打开功能。

## 建议类型

- [剪贴板应用建议](./clipboard-apps.md)：复制链接或文本后，建议使用匹配的应用打开。
- [SMS 验证码建议](./sms-codes.md)：收到验证码短信后，提供复制或填入操作。
- [手电筒建议](./torch.md)：手电筒开启时提供快速关闭操作。
- [音乐建议](./music.md)：连接耳机后，建议启动指定的音乐应用。

## 显示方式

智能建议复用系统剪贴板浮层显示，不属于通知。新的建议会替换当前浮层，SystemUI 重启后不会恢复。

建议只在设备已解锁且用户设置已完成时显示。锁屏期间错过的建议不会在解锁后补弹。

## 适用范围

智能建议只提供快捷操作，不会自动打开应用、填入验证码、关闭手电筒或播放音乐。目标应用缺失、输入框不支持填入、内容未命中规则或设备不具备对应能力时，建议可能不会出现或无法完成操作。
