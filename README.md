# 应用跳转控制

应用跳转控制用于管理一个应用打开另一个应用页面的行为，例如网页跳转购物应用、内容应用拉起商店，或应用之间相互唤起。

## 开启

进入 **uwuSettingsExt → 应用跳转**。总开关默认开启，关闭后所有规则暂停生效，但不会被删除。

## 设置规则

可以从三个角度配置跳转：

- 某个应用作为来源，打开其他应用时采用的规则。
- 某个应用作为目标，被其他应用打开时采用的规则。
- 精确的“来源应用 → 目标应用”配对规则。

每项规则可以设为：

- **始终允许**：直接打开目标页面。
- **询问**：跳转前显示确认窗口。
- **始终阻止**：中止跳转并显示简短提示。

精确配对规则优先于来源和目标的通用规则。

## 询问窗口

询问窗口会显示来源与目标应用的名称和图标。选择允许或不允许后，本次跳转按所选结果处理。

勾选“记住我的选择”会把结果保存为这两个应用之间的配对规则；不勾选则只对本次有效。点按窗口外或按返回键相当于取消，不会打开目标应用，也不会保存规则。

## 适用范围

该功能只管理 Activity 页面启动，不会阻止 Service、Broadcast、Provider、Binder 或网络通信。同一应用内部页面、系统来源、桌面、系统解析器、权限控制器、文件或照片选择器等必要流程会被豁免。

需要向来源页面返回结果的启动通常保持 Android 原有行为。卸载应用不会自动删除旧规则，相同包名重新安装后，旧规则可能再次生效。
