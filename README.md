# Prism

Prism 可从当前屏幕捕获图像，框选文字或图片后执行识别、复制和文件导出。

## 启用三指手势

进入 **uwuSettingsExt > 智能 > Prism**，启用「三指上滑」。该选项默认关闭。

设备解锁且屏幕亮起时，让三根手指近乎同时接触屏幕并连续向上滑动。符合触发条件后，SystemUI 截取默认显示屏的画面并打开 Prism 捕获页。

下列情况会取消手势：额外的第四根手指、手指过早离开屏幕、移动距离不足、明显偏离向上方向，或两次触发间隔过短。

## 选择与导出

在捕获页创建选区，可移动、调整大小或删除选区。

| 选区 | 支持的操作 |
| --- | --- |
| 文字 | OCR 识别、复制文本、导出 TXT 或 PDF |
| 图片 | 保存至 Pictures、导出图片或 PDF |

文字识别可以使用依赖 uwuAICore 和已下载模型的本地模型，也可以选择 Prism 内置的中英文 Tesseract。uwuAICore 不可用时，Tesseract 仍可独立工作。

## 临时文件与限制

捕获内容和 OCR 裁剪默认保存为临时文件，正常退出时清理。只有明确执行保存或导出后，文件才写入长期存储。触发手势本身不会把截图加入相册。

- 锁屏、熄屏和非交互状态不执行捕获，也不会解锁后补执行。
- 当前只捕获默认显示屏。
- 手势识别成功后会接管该触摸序列，前台应用可能收到取消事件。
- Prism 启动失败时，系统删除本次临时截图。
