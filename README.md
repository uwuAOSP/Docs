# 自定义字体

自定义字体把用户导入的字体注册到 Android 字体服务，并覆盖系统默认的 `sans-serif` 字体族。新启动的应用会开始使用所选字体；重启设备后可更新全部系统界面。

## 导入字体

进入 **uwuAOSP Plus → 界面设置 → 自定义字体**，可以选择：

- 单个 TTF 或 OTF 字体。
- 包含多个 TTF/OTF 文件的 ZIP 压缩包。

ZIP 会在本机解压。有效字体会长期保存在应用私有的 `CustomTTF` 目录中，并按 PostScript 名称、字重和样式列出。损坏文件、非字体文件和不符合签名的文件会被忽略。

为避免异常压缩包耗尽空间，导入过程限制为最多 256 个归档条目、128 个字体、单个字体 64 MiB、字体总量 256 MiB。

## 预览与应用

选择字体后，页面使用该字体显示以下预览：

```text
老人正梦见狮子。
The quick brown fox jumps over the lazy dog.
0123456789
いろはにほへと ちりぬるを
```

点按“应用所选字体”后，系统字体服务会验证并安装字体。失败时页面会显示具体原因，例如文件无效、签名不受支持、存储不足或系统字体服务不可用，而不是只显示内部错误码。

## 恢复默认字体

选择“恢复默认字体”会移除系统中的自定义字体覆盖，并清空已导入的 `CustomTTF` 文件。恢复后，新启动的应用使用系统默认字体；重启可让全部界面同步更新。

字体文件只在设备本地处理，不会上传到网络。部分应用使用自带字体或图形资源，因此不会跟随系统字体变化。
