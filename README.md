# 单独控制应用音量

可分别调节正在播放声音的应用音量，不影响全局媒体音量。

## 配置

进入 **设置 > 提示音和振动 > 音频 > 控制特定应用的音量**。该功能默认关闭。

开启后，从系统音量面板进入应用音量列表，为正在播放的应用设置 0–100 的音量。

## 音频处理

SystemUI 通过 `AudioManager` 查询播放应用，将界面值 0–100 转换成 AudioFlinger 的 `0.0–1.0` 增益。

AudioFlinger 在混音阶段应用各应用的增益。全局媒体音量仍控制整体输出。

同包名新建音频轨道继承当前增益，控制接口由 `MODIFY_AUDIO_ROUTING` 权限保护。

应用音量保存在 AudioFlinger 运行时，重启设备或音频服务后恢复默认。
