# 外接屏桌面

外接屏桌面使用 Android 的自由窗口模式，在外接显示器上提供任务栏和窗口标题栏。

## 开启与连接

进入 **uwuAOSP Plus > 系统与桌面 > 外接屏桌面**，启用总开关。

| 选项 | 行为 |
| --- | --- |
| 遮盖本机屏幕 | 外接桌面运行时，在内置屏幕显示黑色连接提示；断开最后一块外接屏后恢复 |
| 允许 scrcpy 虚拟屏 | 使用 `scrcpy --new-display` 创建桌面显示器 |

连接支持视频输出的 USB-C 或 HDMI 显示器后，即可使用外接桌面。

也可以通过支持新显示器模式的 scrcpy 创建虚拟屏：

```sh
scrcpy --new-display=1920x1080
```

显示密度和方向由系统自动调整。

## 断开恢复

拔掉外接屏幕后，系统恢复本机显示和输入，并结束外接桌面会话。
