# 智能建议

智能建议根据剪贴板、短信和设备状态，显示对应的快捷操作。

进入 **uwuSettingsExt > 智能 > 智能建议**，开启需要的功能并配置规则。

## 建议类型

- [剪贴板应用建议](./clipboard-apps.md)：复制匹配链接或文本后，提供目标应用入口。
- [音乐建议](./music.md)：连接指定类型音频设备后，提示打开所选音乐应用。
- [SMS 验证码建议](./sms-codes.md)：识别短信中的验证码，提供复制和填入操作。
- [手电筒建议](./torch.md)：手电筒开启后，提供关闭操作。

## 显示

建议显示在系统剪贴板浮层中。新建议出现时会更新浮层内容，点击相应按钮即可执行操作。
