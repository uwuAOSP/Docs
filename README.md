# 应用跳转控制

按应用管理跨应用页面跳转，例如浏览器跳转到购物 App。

## 配置规则

进入 **uwuSettingsExt > 应用跳转**。总开关默认开启；关闭后暂停执行现有规则，不删除配置。

支持以下规则：

| 范围 | 匹配条件 |
| --- | --- |
| 来源应用 | 指定应用尝试打开其他应用 |
| 目标应用 | 其他应用尝试打开指定应用 |
| 应用配对 | 精确指定「来源应用 → 目标应用」 |

每项规则支持「始终允许」「询问」和「始终阻止」。配对规则的优先级高于来源或目标通用规则。

## 询问窗口

选择「询问」后，系统在跳转前显示来源和目标应用的名称及图标。

- 允许或拒绝：处理本次跳转。
- 「记住我的选择」：保存该应用配对规则。
- 返回或点按窗口外：取消跳转。

## 生效范围

只控制跨应用 `Activity` 启动，系统组件与应用内部跳转继续使用 Android 原有行为。

规则按包名保存，卸载应用不会自动删除规则。
