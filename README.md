# Prism

Prism 可以截取当前屏幕，让用户框选文字或图片进行识别、复制和导出。

## 开启

进入 **uwuSettingsExt → 智能 → Prism**，打开“三指上滑”。该开关默认关闭。

## 捕获屏幕

在设备已解锁且屏幕亮起时，让三根手指近乎同时落下并明显向上滑动。识别成功后，SystemUI 截取默认显示屏的完整画面，并自动打开 Prism 捕获页。

手势需要快速、连续且以竖直向上为主。出现第四根手指、某根手指过早抬起、移动距离不足或两次触发间隔过短，都会取消操作。

## 选择内容

进入捕获页后，可以在截图上创建、移动、缩放或删除两类区域：

- **文字区域**：执行 OCR、复制识别文本，或导出 TXT/PDF。
- **图片区域**：保存到 Pictures，或导出图片/PDF。

本地模型依赖 uwuAICore 和已下载模型，也可以选择 Prism 内置的中英文 Tesseract。AI Core 不可用时，Tesseract 仍可能正常工作。

## 文件保存

屏幕捕获和 OCR 裁剪默认使用临时文件，正常退出后会自动清理。只有用户明确选择保存或导出，内容才会永久写入存储空间；触发手势本身不会把截图自动保存到相册。

## 适用范围

- 锁屏、熄屏或非交互状态下不会捕获，也不会在解锁后补触发。
- 当前只捕获默认显示屏，不提供多显示器选择。
- 成功手势会接管当前触摸序列，前台应用可能收到一次手势取消。
- Prism 启动失败时，本次临时截图会被删除。
