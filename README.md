# 单独控制应用音量

单独控制应用音量为当前正在播放声音的应用提供独立增益，不改变全局媒体音量。适合同时播放音乐、游戏、导航或通话辅助音频时分别调整响度。

## 开启

进入 **设置 → 提示音和振动 → 音频 → 控制特定应用的音量**。该开关默认关闭。

开启后，系统音量面板会显示应用音量入口。进入面板后，可以对当前存在播放轨道的应用分别设置 0–100 的音量。应用停止播放并释放音频轨道后，可能暂时从列表中消失。

## 工作原理

SystemUI 从 AudioManager 获取当前应用音频轨道，并把 0–100 的界面值转换为 AudioFlinger 使用的 `0.0–1.0` 增益。AudioFlinger 在混音阶段将应用增益与媒体流音量、端口音量相乘，因此：

- 调低某个应用不会改变其他应用的音量。
- 系统媒体音量仍然控制最终整体响度。
- 新建的同包名播放轨道会继承当前 AudioFlinger 进程中保存的应用增益。

该接口受 `MODIFY_AUDIO_ROUTING` 权限保护，普通第三方应用不能直接修改其他应用的音量。

## 限制

应用增益保存在 AudioFlinger 运行时状态中，不是长期用户配置。音频服务或设备重启后，应用音量会恢复默认值。没有独立音频轨道、使用特殊直通路径或由其他进程代为播放的应用，可能不会以预期名称出现在列表中。
