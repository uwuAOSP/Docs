# 应用剪贴板权限

按应用控制剪贴板读取和写入，支持允许、询问和拒绝。

## 设置策略

进入 **uwuAOSP Plus > 隐私与安全 > 应用剪贴板权限**。

| 策略 | 行为 |
| --- | --- |
| 允许 | 保持 Android 默认处理 |
| 询问 | 访问剪贴板前显示确认窗口 |
| 拒绝 | 拒绝应用读取及写入剪贴板 |

策略按用户保存，默认允许。

## 询问窗口

确认窗口显示请求应用，以及本次操作属于读取还是写入。

- 未勾选「写入永久规则」：拒绝仅影响当前请求；允许授予约 10 秒临时访问权限。
- 勾选「写入永久规则」：将本次结果保存为应用持久策略。
- 关闭窗口或按返回键：拒绝本次请求，不保存规则。

同一应用短时间内重复请求时，系统会限制弹窗次数。

## 生效范围

策略作用于 `ClipboardService` 的读写请求。Android 原有的输入法和系统组件豁免照常生效。
