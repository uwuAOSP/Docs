# Launcher 一览

Launcher 一览显示在主屏幕第一屏顶部，包括日期、天气、闹钟、计时器和媒体信息。

## 显示内容

- **日期**：点按打开日历。
- **天气**：显示当前天气和预报，点按打开天气页面。
- **闹钟**：显示下一次闹钟。
- **计时器**：显示正在运行的计时器。
- **媒体**：显示标题、副标题和封面，点按打开对应播放器。

播放音乐时，可横向切换状态页和媒体页。

## 设置

在 Launcher 设置中：

- 「显示一览」控制第一屏状态区域，默认开启。
- 「使用 Smartspacer」允许已安装并获得授权的 Smartspacer 提供卡片，默认关闭。

未启用 Smartspacer 时使用内置一览。

## 数据来源

日期和闹钟读取 Android 系统服务，天气、计时器和媒体信息由系统提供器提供。
